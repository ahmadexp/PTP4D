# PTP4D 0.4

**PTP4D stands for PTP for DOS.** This first public release identifies a TimeStick v3, reads its hardware clock, and runs a PTP follower through PicoPCMCIA from real-mode DOS.

## Download

- [PTP4D.EXE](https://github.com/ahmadexp/PTP4D/releases/download/v0.4/PTP4D.EXE): ready-to-run DOS executable, 61,016 bytes.
- [SHA256SUMS](https://github.com/ahmadexp/PTP4D/releases/download/v0.4/SHA256SUMS): executable checksum.

Copy `PTP4D.EXE` to `C:\` on the DOS computer. Start the compatible TimeStick grandmaster first, then run:

```dos
C:\PTP4D /HOST
C:\PTP4D /PTP 0
```

Press Esc to stop. Use `/PTP 60` for a one-minute run, `/CLOCK` for clock snapshots, or `/?` for help. `/HOST` saves USB host ownership; `/CARD` restores card-managed USB.

## Tested requirements

- IBM PC110 running MS-DOS 6.22.
- PicoPCMCIA v4.4 with firmware v0.22, matching `PICOCARD.EXE`, and a readable microSD card.
- TimeStick v3 with the compatible USB MIDI timing firmware, connected directly to PicoPCMCIA's USB-C breakout.
- A second TimeStick acting as a hardware grandmaster, connected by Ethernet.

The TimeStick firmware runs the PI servo in domain 42 at 4 Hz. PTP4D synchronizes the TimeStick hardware clock; it does not set the DOS system clock. Windows is not supported by this build.

See the [setup guide](https://github.com/ahmadexp/PTP4D/blob/v0.4/docs/setup.md) for the Linux grandmaster and optional SSH/COMrade controller. Firmware, DOS, and the compiler are supplied separately.

## Validation

The executable matches a fresh Borland C++ 3.1 build byte for byte. Portable protocol tests and host-tool checks pass. A one-minute hardware run completed 237 exchanges with no grandmaster timestamp errors; all 128 retained exchanges matched the hardware timestamp logs and independent offset calculations.

During the final 40 exchanges, the reported mean offset was 2.175 ns and the maximum absolute offset was 20.5 ns. These are PTP-reported results under the symmetric-path assumption, without external PPS or UTC calibration. Screenshots and timing evidence are included in the repository.
